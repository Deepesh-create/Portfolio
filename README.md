# Deepesh Kumar Duria | Portfolio

Single-file, scroll-driven 3D portfolio (Three.js + GSAP + Tailwind via CDN). No build step.

## Deploy on GitHub Pages
1. Create a repo, e.g. `Deepesh-create.github.io` (or any name).
2. Upload `index.html` (and this README) to the repo root.
3. Go to **Settings > Pages**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. Your site goes live at `https://<username>.github.io/<repo>/` within a minute or two.

## Run locally
Open `index.html` in a browser (needs internet for the CDN scripts).
